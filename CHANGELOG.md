# Changelog

## 1.1.0 — 2026-08-21

### Added
- offline 1.x report conformance validation and machine-readable compatibility manifest
- private-first external-pilot workspace scaffolding and evidence-retention protocol
- non-leaking sanitization scanner covering contact, commercial, metadata, hidden-content and structural XLSX leakage signals
- guarded `bidlint-pilot` execution with strict manifest validation, repeated deterministic output digests and corpus SHA-256 evidence
- immutable approved-baseline replay verification with `bidlint-pilot-verify`
- explicit `bidlint-pilot-gate` requiring clean sanitization, deliberate human approval, zero unresolved release-blocking limitations and exact baseline replay
- conservative XLSX specification requirement blocks with independent worksheet selection and explicit unscoped-row coverage evidence
- production-shaped conflict-path CPU and peak-memory benchmark gate
- validated wheel artifact retention for isolated private-pilot replay

### Fixed
- empty external pilots can no longer pass with zero evaluated requirements
- grade/designation values such as Grade 304 and A15 remain qualitative rather than accidental numeric thresholds
- composite dimensions remain qualitative until deterministic multidimensional comparison is supported
- standard OOXML schema URLs no longer create sanitization URL false positives
- unrelated fuzzy parameter names without lexical overlap require stronger evidence before matching
- commercial XLSX values hidden behind currency number formats are detected by the sanitization scanner

### Validation
- real external drainage-schedule-derived sanitized pilot completed with six evaluated top-level requirements
- sanitization: 0 blockers / 0 review findings
- pilot: passed, deterministic and conformant across repeated runs
- human baseline and manual specification-scope review deliberately approved
- approved replay: exact match, 0 mismatches
- full Python 3.11 / 3.12 / 3.13 tests, wheel smoke, runtime dependency audit and deterministic benchmark gates required for release

### Compatibility
- no change to frozen BidLint 1.x `PASS / DEVIATION / MISSING / REVIEW` semantics
- no commercial scoring, contractual acceptance or inferred knockout criteria
- release approval is software baseline evidence, not supplier compliance acceptance
