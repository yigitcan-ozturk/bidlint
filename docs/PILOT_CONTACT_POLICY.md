# Pilot Contact Policy

The BidLint early-adopter phase uses targeted, relevant outreach rather than bulk unsolicited messaging.

## Principles

- Contact practitioners whose work plausibly includes technical bid evaluation, specifications, vendor submittals or engineering procurement.
- Explain that BidLint is open source and that the request is for technical feedback, not a disguised sales pitch.
- Never request confidential customer or supplier documents for public testing.
- Prefer sanitized, recreated or repository sample data.
- Do not repeatedly follow up when there is no interest.
- Measure successful outreach by real product usage and useful feedback, not message volume.
