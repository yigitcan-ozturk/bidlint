# bidlint v1.1.0

Released 2026-08-21.

BidLint 1.1.0 is the production-adoption release for the stable 1.x contract. It adds repeatable pilot evidence, sanitization controls and explicit release governance without changing the deterministic compliance semantics frozen in 1.0.0.

## Production-adoption evidence chain

The 1.1 line adds:

- `bidlint-contract` for offline validation of the frozen 1.x report contract;
- `bidlint-pilot-init` for private-first external-pilot workspaces;
- `bidlint-pilot-scan` for non-leaking sanitization preflight;
- guarded `bidlint-pilot` execution with repeated deterministic digests, corpus hashes and conformance evidence;
- `bidlint-pilot-verify` for immutable approved-baseline replay;
- `bidlint-pilot-gate` for deliberate human sanitization/technical approval and release readiness;
- explicit XLSX specification scope-coverage evidence so populated rows outside the supported contiguous requirement block cannot be silently claimed as evaluated.

## External sanitized pilot

The final release gate used a real external drainage-channel/floor-gully tender family retained privately. Public repository evidence contains no raw customer documents. The approved sanitized pilot:

- evaluated six top-level technical requirements;
- produced six conservative `REVIEW` findings rather than false PASS decisions;
- completed with zero sanitization blockers and zero sanitization review findings;
- was deterministic and 1.x conformant across repeated runs;
- exposed 37 later populated specification rows as a deliberate manual-scope boundary;
- received explicit human baseline/scope approval;
- replayed against the approved baseline with zero mismatches.

Non-sensitive evidence digests are retained in Issue #39.

## External-derived hardening

Real-pilot work produced minimized regressions for:

- zero-requirement pilot rejection;
- grade/designation values that must stay qualitative;
- composite dimensions that must not be reduced to one-axis numeric comparisons;
- unscoped XLSX specification rows;
- OOXML schema URL sanitization noise;
- unrelated fuzzy parameter matches;
- commercial XLSX values represented only through currency cell formats.

## Packaging and CI

Release candidates are validated through:

- Python 3.11, 3.12 and 3.13 ruff + pytest;
- wheel/sdist build, twine validation, installed CLI smoke and `pip check`;
- runtime dependency audit;
- deterministic 20,000-fact consolidation benchmark;
- production-shaped conflict-path CPU and peak-memory profile.

## Compatibility and decision boundary

BidLint 1.1.0 does **not** change the frozen 1.x meaning of `PASS`, `DEVIATION`, `MISSING`, `REVIEW`, compliance scoring or explicit knockout statuses. It does not add commercial scoring, automatic contractual acceptance or inferred knockout criteria.

The external-pilot approval is a software baseline/release-evidence decision. It is not supplier compliance acceptance and does not claim unsupported item-level schedule rows were automatically evaluated.
