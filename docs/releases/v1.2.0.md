# bidlint v1.2.0

BidLint 1.2.0 adds a private-first, evidence-bound supplier collaboration workflow while preserving the frozen BidLint 1.x deterministic compliance semantics.

## Supplier collaboration workflow

- offline supplier clarification intake bound to the originating clarification register
- buyer-side response ingestion and provenance-preserving review
- explicit evidence-adequacy assessment separate from compliance status
- immutable supplier revision history with conflict preservation
- deterministic response-readiness preflight
- evidence-file manifests with exact byte provenance
- requirement-level evidence-file reference validation
- evidence-manifest binding through review, pilot packaging, attestation and portal-readiness checks
- fail-closed pilot workspace status and next-action reporting

## Additional validation path

The release also includes the executable blind lab-furniture pilot controls, providing a second production-shaped validation path with explicit provenance and freeze contracts.

## Compatibility boundary

BidLint 1.2.0 does not change the frozen 1.x `PASS / DEVIATION / MISSING / REVIEW` meanings or deterministic scoring contract. Evidence adequacy, workflow state and portal readiness are separate signals and cannot silently upgrade technical compliance.

## Portal boundary

No hosted supplier portal is shipped or claimed by this release. The real supplier return tracked in issue #72 remains a private external-validation gate. Hosted portal scope stays deferred until that exact artifact completes the executable validation workflow.

## Validation required before release

The release branch must pass the existing CI matrix on Python 3.11, 3.12 and 3.13. The stable `v1.2.0` tag and GitHub Release must be created only from the final merged release commit.
