# Growth / Early Adopter Materials

This folder contains the operating materials for the BidLint early-adopter phase:

- [`EARLY_ADOPTER_GUIDE.md`](EARLY_ADOPTER_GUIDE.md) — 10-minute practitioner onboarding
- [`DEMO_SCRIPT.md`](DEMO_SCRIPT.md) — 25-30 second sample-data demo plan
